📋 Step 1: OpenSSH 설치 (RDP 접속 필요)

SSH가 설치되지 않은 미니 PC (SSH ✗)는 RDP로 접속하여 아래 절차를 수행하세요. OpenSSH만 설치합니다.

  1. 대시보드에서 🖥️ RDP 버튼으로 해당 PC에 RDP 접속
  2. PowerShell을 관리자 권한으로 실행
  3. 아래 명령어를 복사하여 실행: 
    Invoke-WebRequest -Uri "http://10.254.170.201:4310/install-ssh.ps1" -OutFile "$env:TEMP\install-ssh.ps1"
Set-ExecutionPolicy Bypass -Scope Process -Force
& "$env:TEMP\install-ssh.ps1"
  4. install-ssh.ps1이 자동으로 다음을 설치:
    • OpenSSH Server (포트 22)
    • 방화벽 규칙 (SSH 22, RDP 3389)
    • 네트워크 프로파 Private로 변경
  5. 설치 완료 후 RDP 종료 → 대시보드에서 SSH ✓ 확인
  6. SSH ✓ 확인 후 Step 2에서 프로그램 원격 설치 진행

🚀 Step 2: 프로그램 원격 설치 (SSH 필요)

SSH가 설치된 장비 (SSH ✓)에 bootstrap.ps1을 원격 전송하여 자동 설치합니다. SSH가 없는 장비는 Step 1을 먼저 완료하세요.
